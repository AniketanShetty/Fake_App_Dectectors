# Scope

- Platform: Android (Google Play Store).
- Brand: PhonePe (UPI payments app).
- Domain: UPI / digital payments.

- Threats covered:
  - Fake / lookalike apps using the PhonePe name or branding.
  - Typosquatted package names (e.g., `com.ph0nepe.upi` instead of `com.phonepe.app`).
  - Reward/bonus/cashback apps pretending to be related to PhonePe.

- Out of scope:
  - iOS App Store.
  - Sideloaded APK malware (outside Play Store).
  - Web phishing, SMS phishing, overlay attacks.
